2. Latest Project: Python Label Printing Service

Real-world production microservice developed for automated industrial label printing in a manufacturing setup.

Python Label Printing Service

Python 3.x RabbitMQ Windows Services PyWin32 ZPL / TSPL Zebra Thermal Printers Manufacturing MES

Project Purpose & Workflow:

Designed and deployed an automated, background Windows Service that listens for print payload requests dispatched from the Manufacturing Execution System (MES) via RabbitMQ message queues. It eliminates manual printing errors by sending raw printer command language (ZPL/TSPL) directly to thermal barcode and serial label printers across active production lines.

MES Core ➔ (AMQP Message) RabbitMQ Queue ➔ (Consume Payload) Python Windows Service ➔ (Win32 Spooler) Zebra Label Printer

Message Processing & Printing Mechanism:

  • Queue Listener: Utilized the pika library to asynchronously consume print job requests from dedicated RabbitMQ exchanges.
  • Payload Parsing & Validation: Validates incoming JSON payload schemas containing barcode strings, product serial numbers, timestamps, and printer target IP/USB handle.
  • Raw Print Dispatch: Leverages win32print to interface directly with Windows Spooler API, pushing ZPL commands straight to Zebra printers without UI print dialog delays.
  • Exception & Re-queue Handling: Automatically logs printer offline or paper-out events, gracefully dead-lettering unprintable messages to avoid queue bottlenecks.

My Role & Verified Results:

  • Engineered the Python script and packaged it as a persistent, auto-restarting background Windows Service using NSSM / PyWin32.
  • Reduced label dispatch latency from ~12 seconds (manual step) to < 1 second automated execution.
  • Verified printer performance through 500+ test print cycles ensuring 100% barcode readability and zero queue memory leaks.
